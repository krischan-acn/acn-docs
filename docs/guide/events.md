# Events

Trade shows and conferences ACN covers, such as BEX Asia or MCE Asia. Events **do** save to the newswire for real.

## The list

All events, 50 per page.
- Search covers every event.
- Filters: **Status** (upcoming, running, past, unpublished), **Year**, **Organiser**.

## Adding or editing an event

**+ New event**, or click an event. The fields:

| Field | Notes |
| --- | --- |
| Event name | Required |
| Start date, end date | The end can't be before the start |
| Location | Free text |
| Organiser website | |
| Event image | The image's **file name** only. The image itself must already be on the server. |
| Organiser company number | Links the event to a company, which lets the event page list that company's releases |
| Published on the site | Untick to hide the event from the newsroom |

Buttons:
- **Save** sends the event straight to the newswire.
- **Discard** throws away your changes.
- **Delete** asks for confirmation first.

If a save fails, your changes are kept. Next time you open the event you'll see "Unsent changes restored", and the next save sends them.

## Press releases under an event

The event page lists press releases from the **organiser company** in the event's year. Most events have no organiser number yet, so they say "No organiser id, so no release feed is possible". Add the organiser's company number to fix that.

## On the newsroom

Published events appear on the newsroom's **Events** page within about an hour.
